# Sources, provenance and licenses

Prepared 2026-10-04.

## Original guidance

The user supplied three private style-reference screenshots and approved a previous portfolio's hand-drawn outcome. This repository distills general visual traits in original wording; it does not copy the referenced paper's method, full prompt or figures. Screenshots are not redistributed.

The fixed style/prompt/code and layer manifests were authored for this repository. Original artwork was generated with the built-in image_gen tool on 2026-10-04. Full generation prompts are [examples/art-prompts.json](examples/art-prompts.json); original PNGs are retained in examples/art. Presentation crops of the method atlas are identified as crops. Generated drawings are conceptual, not experimental photographs, measured point clouds or research outcomes.

## Example data

The hybrid example CSV is deterministic synthetic teaching data generated by examples/build_examples.py: 25 hourly values, an analytic sinusoid and a second explicitly synthetic signal. It is not an actual sensor record. The exact formula, seed-free perturbation and units are retained with the source.

No personal application PDFs, original research measurements, publication figures or credentials are included. MIT covers original repository material; fonts keep their separate licenses.
