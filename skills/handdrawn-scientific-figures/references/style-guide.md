# Natural scientific sketch style

The fixed visual language combines approachable pen illustration and precise scientific communication. It is derived from the user's approved portfolio outcome and three supplied style references; their paper-specific content is not part of this skill.

## Typography and color

| Element | Preset |
|---|---|
| Main title | Kalam Bold |
| Short label / marginal note | Patrick Hand |
| Technical body, numerical label, unit, tick | DejaVu Sans; Bold for emphasis |
| Mathematical symbols | Matplotlib MathText, Computer Modern fontset |
| Foundation | Pure white #FFFFFF; charcoal #252525 |
| Accent palette | Powder blue #BFD8F0, lavender #DCC7EB, butter yellow #FFE5A3, orange #F2B37E, mint #C8E6C1 |
| Secondary color | Warm gray #F1F1EF; restrained coral #F3B7B0 when a failure condition actually exists |

The authoritative machine preset is [style.json](../assets/style.json). Declare color roles per figure; a purple module is not automatically a latent state in an unrelated project. Use text/shape as well as color to distinguish groups.

## Composition

Start from the scientific message. Draw real entities: cameras, sensing surfaces, rivers, rooms, sample objects, laboratory equipment, image planes and software surfaces. Use a dominant scene or mechanism, with supporting inputs and annotations. Allocate different space to different roles instead of arranging equal-sized cards.

Fine irregular contours, hand underlines and occasional dashed groups create the sketch character. Keep the outer background white, not paper-textured. Small local pencil marks are allowed inside drawn objects. Shadows, when needed at all, are small and local.

Keep most labels to two to four words; explain details in the caption. Titles must describe the subject rather than advertise significance. Use real vocabulary and source-supported relationships.

## Arrow grammar

A structural arrow means a defined input, output, dependency or process direction. A dashed observation beam means observation only, not a proven causal influence. A feedback route ends at the specified previous stage. Separate feedback from the main path and never route it through a text label.

Geometric diagrams must preserve shared coordinate references. Explicitly distinguish floor-to-object height from camera distance or platform-to-object height when those meanings matter.

## Paper and presentation presets

Paper: default width 180 mm, height 110 mm, 300 dpi, title 16 pt, note 10 pt and body 8.5 pt. Treat these as internal defaults; supplied venue rules override size/typography. Check the full figure at print scale, with authored text at least 8 pt unless the venue specifies otherwise.

PPT: physical canvas 13.333 × 7.5 inches, 3840 × 2160 PNG, title about 30 pt, labels about 24 pt and body about 18 pt. Simplify information for projection rather than enlarging a dense manuscript screenshot. Keep the same visual identity.

## What to avoid

Avoid neon, glow, glossy 3D, glass panels, full-canvas gradients, thick shadows, corporate dashboards, repeated metric cards, dense SmartArt, irrelevant mascots and emoji clutter. Avoid mechanically perfect decorative outlines, but do not make the figure messy or childish.

Never distort data points, simulate unsupported result distributions, convert aggregates into individual observations, imply causal conclusions from associations or draw model outputs as if they were real evidence. Transparent backgrounds are used only when specifically required for an insert.
