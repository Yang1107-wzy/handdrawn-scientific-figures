# 以后如何让 AI 保持这套风格

普通任务可以直接说：

```text
使用 $handdrawn-scientific-figures，按照这个论文的方法部分画方法图。
核心信息是……
必须保留的输入、输出和反馈关系是……
图内精确文字和公式是……
用途：论文 / PPT。目标尺寸：……
材料：附上的论文、CSV 和原图。
```

聊天界面没有 skill 时，复制 [总提示词](../skills/handdrawn-scientific-figures/references/master-prompt.md) 并填上述内容。方法、场景和数据可以变；视觉语言段保持不变。

想修图时描述具体位置和关系，例如“让现场相机占左侧更多空间；保留公式不变；反馈线从检查节点回到对齐，走下方留白”。避免只说“更顶刊、更高级、更不 AI”，这些词不能指定可验证的构图。

论文图在最终缩小尺寸查看；PPT 在投影尺寸查看。确认指标来自哪份数据、每个箭头表示什么，以及图中的场景属于概念说明还是实际证据。没有逐样本误差时不要让 AI 补出分布曲线。
